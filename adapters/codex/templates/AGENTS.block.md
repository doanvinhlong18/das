## dev-agent-skills

- Use `$guided-development` for every non-trivial task: bug fix, new feature,
  refactor, performance optimization, SQL or stored procedure change, code
  investigation and analysis. Skip it only for genuinely trivial mechanical
  edits.
- Core skills (`guided-development`, `task-understanding`, `code-investigation`,
  `task-decomposition`, `incremental-implementation`, `verification`,
  `understanding-gate`) define the workflow and are authoritative.
- Domain skills (`java`, `spring`, `sql`, `angular`, `git`, `testing`) are used
  only for technical reasoning and never change workflow state.
- Investigate with evidence before editing, implement one logical step at a
  time, and verify expected versus observed behavior before moving on.
- Project rules may tighten this workflow but must not weaken it.
